Use Sync New Changes or Resync All to publish.

Sync New Changes

Publish only records that have been created or updated since the last sync. Uses the watermark to skip already-synced records.

Resync All

Clear watermarks and re-sync every published skill and collection from the beginning. Use when recovering from errors or after bulk changes. This can take a long time.

Unpublish All

Remove all published skills and collections from the Credential Registry. Use to clean up dev/test data. This cannot be undone.

Integration Key
Identifies the sync target configuration (e.g. default). Used when multiple Credential Registry destinations exist.
Record Type
skill (RSDs published as Competencies) or collection (Collections). Each type syncs separately.
Watermark
Timestamp of the last successfully synced record for this integration. Incremental sync processes only records updated after this point.
Pending
Number of records not yet synced for this integration.
Status
Outcome of the last run—Ok (N batches), In progress…, or Error. The correlation ID (if present) can be copied for log lookups.
